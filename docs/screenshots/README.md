| File | What to capture |
|---|---|
| `01-telegram-chat-demo.png` | The group chat: a screenshot sent, the bot reply with buttons, an undo |
| `02-google-sheet.png` | The `transactions` tab with a few rows |
| `03-monthly-report.png` | The report message or `/summary` output |

## Before you commit any screenshot: blur or crop

- names, chat IDs, user IDs, phone numbers
- amounts and merchants of real transactions (use test data for the demo)
- the browser address bar (the spreadsheet ID is in the Google Sheets URL)
- any n8n panel showing the **Config** node output (it lists user IDs and the spreadsheet ID), credentials, or execution data with real messages
- your domain or tunnel hostname, if you do not want it public

Tip: take the demo screenshots with a test group and made-up transactions.
